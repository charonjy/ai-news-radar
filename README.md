# AI 资讯雷达

每 30 分钟自动抓取 AI 行业一手动态，由 AI 打分、写中文摘要，把重要的推送到飞书群。全部使用免费服务，无需服务器。

## 它是怎么工作的

1. **GitHub Actions** 定时运行 `main.py`（免费，GitHub 提供的云端电脑）
2. 抓取 `config.yaml` 里列出的信息源（官方博客、GitHub 版本发布、新闻聚合、Hacker News）
3. 和 `data/seen.json`（已读记录）比对，只留下新内容
4. 调用 **GitHub Models**（GitHub 自带的免费 AI 额度）合并重复、打分、写摘要
5. 分数达标的通过 **飞书机器人** 推送；AI 不可用时自动降级为推送原标题

## 部署步骤

### 1. 创建飞书机器人
1. 在飞书里建一个群（可以只有你自己）
2. 群设置 → **群机器人** → 添加机器人 → **自定义机器人**
3. 复制 **Webhook 地址**
4. 安全设置勾选 **签名校验**，复制密钥

### 2. 把密钥存到 GitHub
仓库页面 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**，添加两个：

| Name | 值 |
|---|---|
| `FEISHU_WEBHOOK` | 第 1 步的 Webhook 地址 |
| `FEISHU_SECRET` | 第 1 步的签名密钥 |

### 3. 启动
仓库页面 → **Actions** → 左侧选 **AI 资讯雷达** → **Run workflow**。
一两分钟后飞书群会收到一条绿色的「启动成功」消息，之后每 30 分钟自动运行。

## 日常调整（只改 `config.yaml`）

- **加信息源**：在 `sources` 下照格式加一段 `name` + `url`
- **推送太多 / 太少**：调 `min_score`（调高 = 只推更重要的）
- **改关注方向**：改 `interests` 里的描述，AI 会据此打分

## 已知限制

- **X（推特）没有直接抓取**：免费方案拿不到 X 数据，目前通过新闻聚合间接覆盖马斯克、Altman 等人的重要言论，会比 X 原帖晚一些。
- GitHub 的定时任务高峰期可能延迟几分钟到十几分钟。
- 仓库如果 60 天没有任何活动，GitHub 会暂停定时任务并发邮件提醒，点邮件里的链接重新启用即可。
